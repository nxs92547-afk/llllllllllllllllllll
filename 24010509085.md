## Projenin Amacı ve Kısa Açıklaması
Bu projenin amacı, yapay zeka (Google Gemini) destekli bir web uygulaması geliştirerek kullanıcıların sadece metin ile komut vererek HTML, CSS ve JavaScript tabanlı basit oyunlar üretebilmesini sağlamaktır. Kullanıcılar asistanla sohbet ederek oyun fikirlerini koda dönüştürebilir ve asistanın ürettiği kodları entegre canlı önizleme penceresinde anında test edebilirler.

## Kullanılan Teknolojiler / Kütüphaneler
- **Arka Yüz (Backend):** Node.js, Express.js
- **Ön Yüz (Frontend):** HTML5, CSS3, Vanilla JavaScript
- **Yapay Zeka:** Google Generative AI (`@google/generative-ai` kütüphanesi ve `gemini-2.0-flash` modeli)
- **Ek Kütüphaneler:**
  - `cors` (Çapraz kaynak paylaşımı için)
  - `marked.js` (Markdown formatındaki metinleri HTML'e çevirmek için)
  - `FontAwesome` (Arayüz ikonları için)

## Kurulum Adımları
1. Projenin bilgisayarınızda çalışması için sisteminizde **Node.js** yüklü olmalıdır. Yüklü değilse [nodejs.org](https://nodejs.org/) adresinden yükleyin.
2. Bu projeyi GitHub üzerinden klonlayın veya zip olarak indirip bir klasöre çıkartın.
3. Terminal (veya Komut İstemi) uygulamasını açın ve proje klasörünün ana dizinine gidin.
4. Aşağıdaki komutu çalıştırarak gerekli paketleri kurun:
   ```bash
   npm install express cors @google/generative-ai
   ```

## Çalıştırma / Kullanım Talimatları
1. Terminal üzerinden proje dizininde şu komutu çalıştırarak sunucuyu başlatın:
   ```bash
   node server.js
   ```
2. Sunucu başarılı bir şekilde başladığında terminalde `Server listening at http://localhost:3000` mesajı görünecektir.
3. Tarayıcınızı açın ve `http://localhost:3000` adresine gidin.
4. Uygulama açıldığında karşınıza çıkan ekrana geçerli bir **Google Gemini API Anahtarı** girin (Google AI Studio'dan ücretsiz alınabilir).
5. Sol taraftaki sohbet bölümüne nasıl bir oyun istediğinizi yazın (Örn: "Yön tuşlarıyla çalışan basit bir yılan oyunu yaz").
6. Asistan kodu yazdıktan sonra, sağ taraftaki Canlı Önizleme ekranında oyun otomatik olarak çalışacaktır.
